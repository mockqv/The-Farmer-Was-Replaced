# The Farmer Was Replaced

This repository contains scripts for the game "The Farmer Was Replaced".

## Scripts

*   `treeFarm.py`: The main script that executes the tree farm logic.
*   `isEven.py`: A utility module to check if a number is even.
*   `setPos.py`: A utility module to move the character to specific positions on the map.

## How to use

Execute the `treeFarm.py` script in the game.
